# MVP-план фреймворка AnyUI (`anyui`)

## Цель MVP
Создать лёгкий кроссплатформенный UI-фреймворк на Go (с первым бэкендом на чистом Win32) без WebView2 и без зависимости от OpenGL/GPU:
- Один компактный `.exe` без внешних DLL.
- Стабильная работа на Windows 10/11 и Windows Server (включая RDP и виртуалки без видеокарты).
- ~0% нагрузки на CPU в простое (перерисовка по событиям).
- Корректное масштабирование на HiDPI-экранах.
- Внешний вид в стиле Deep Navy (скруглённые карточки, тонкие 1px-бордеры, плавные тогглы, чёткие шрифты).

## Структура пакетов

Код разделён по чётким зонам ответственности:

```text
GoUI/
├── go.mod
├── cmd/demo/main.go          # Тестовый экран (прототип главного окна / настроек)
├── platform/                 # Оконный слой (ОС-зависимый)
│   ├── platform.go           # Общий интерфейс Window, Event, Key/Mouse, Cursor
│   ├── windows_wnd.go        # Win32 окно, WndProc, GetMessage, HiDPI, буфер обмена
│   └── windows_gdi.go        # Вывод BGRA-буфера через StretchDIBits (+ runtime.KeepAlive)
├── render/                   # Программный 2D-рендер (100% чистый Go)
│   ├── canvas.go             # Пиксельный буфер BGRA, ClipRect, FillRect, альфа-блендинг
│   ├── sdf.go                # Скруглённые прямоугольники, 1px-бордеры, круги со сглаживанием
│   ├── font.go               # Загрузка .ttf (golang.org/x/image/font/opentype) + кеш глифов
│   └── icon.go               # Растровые/альфа-маски для иконок
└── ui/                       # Immediate Mode UI и виджеты
    ├── context.go            # Состояние кадра, фокус, hover, active, анимации
    ├── layout.go             # Стек контейнеров (Row, Column, Padding, Gap, Spacer)
    ├── theme.go              # Палитра Deep Navy (цвета, радиусы, отступы)
    └── widgets.go            # Label, Card, Button, Toggle, StatusDot, базовый TextInput
```

## Этапы реализации

### Шаг 1. Каркас и Win32-окно (`platform`)
- Инициализация `go.mod`, подключение `golang.org/x/sys` и `golang.org/x/image`.
- Создание Win32-окна через `CreateWindowExW`, тёмный заголовок окна (`DwmSetWindowAttribute` с мягким фолбэком для старых серверных ОС).
- Цикл событий на `GetMessageW` (0% CPU в простое) + пробуждение через `PostMessageW` при внешних событиях (анимации, сетевые события).
- Вывод `[]byte` (BGRA) на экран через `StretchDIBits` с `runtime.KeepAlive(buf)` и перерисовкой в `WM_PAINT` (чтобы окно не моргало и не замирало при ресайзе).
- Поддержка HiDPI (`GetDpiForWindow` / `WM_DPICHANGED`).

### Шаг 2. Программный 2D-рендер (`render`)
- Буфер `Canvas` (BGRA) с поддержкой `ClipRect` (обрезка по границам карточек и областей).
- `DrawRoundedRect`: быстрая заливка середины + SDF-антиалиасинг на углах и 1px-обводке.
- `DrawCircle`: сглаженные круги и индикаторы статуса.
- `FontManager`: встраивание базового `.ttf` шрифта через `//go:embed`, растеризация глифов через `opentype` с кешированием в альфа-маски и выводом текста.

### Шаг 3. Движок и базовые виджеты (`ui`)
- Менеджер кадра (`BeginFrame` / `EndFrame`): выдача ID виджетам, отслеживание `hover`, `active`, `focus`.
- Простой `Layout`: `Column`, `Row`, `Padding`, `Gap`, `Spacer`.
- Тема `Deep Navy`: цвета фона, карточек, обводок, акцентов и радиусы скруглений.
- Виджеты MVP: `Card`, `Label`, `Button`, `Toggle`, `StatusDot`, базовый `TextInput` (ввод символов, Backspace, курсор, фокус).

### Шаг 4. Демо-экран (`cmd/demo`)
- Сборка прототипа главного окна (карточка с кодом подключения, верхняя панель с инпутом и кнопкой, нижний статус-бар с индикаторами).
- Замер итогового размера `.exe`, потребления ОЗУ, нагрузки CPU в простое и при взаимодействии.
- Проверка запуска на Windows Server / по RDP без GPU.
