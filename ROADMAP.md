# План развития фреймворка AnyUI (`anyui`)

## Концепция и цель
`anyui` — лёгкий, встраиваемый кроссплатформенный UI-фреймворк на Go без WebView2 и без зависимости от OpenGL/GPU.
Ключевые принципы:
- Любое Go-приложение подключает один пакет `anyui` и сразу строит интерфейс без привязки к конкретной предметной области.
- Минимальный размер бинарника, быстрый старт, ~0% нагрузки на CPU в простое.
- Работа на любых машинах, включая серверные ОС, RDP и среды без аппаратного ускорения.
- Полная кастомизация тем, цветов, радиусов, шрифтов и стилей каждого контрола.
- Документация и рабочие примеры в `docs/` и `examples/` создаются параллельно с каждой фазой.

## Целевой API для разработчика

```go
package main

import "anyui"

func main() {
	app := anyui.NewApp(anyui.Config{
		Title:  "My App",
		Width:  1000,
		Height: 650,
		Theme:  anyui.DeepNavyTheme(),
		Tray: &anyui.TrayConfig{
			Tooltip: "My App",
			Menu: []anyui.MenuItem{
				{Label: "Показать", OnClick: func(a *anyui.App) { a.Show() }},
				{Separator: true},
				{Label: "Выход", OnClick: func(a *anyui.App) { a.Quit() }},
			},
		},
	})

	app.Run(func(ui *anyui.UI) {
		ui.Button("btn_save", "Сохранить", anyui.Icon(saveSVG), anyui.Primary())
	})
}
```

## Фазы реализации

### Фаза 1. Архитектура, фасадный пакет и движок анимаций
- **Единый корневой пакет `anyui/` и задел под многооконность:**
  - Публичный фасад (`App`, `Window`, `UI`, `Config`, `Theme`, `Option`), скрывающий внутренние детали `platform/`, `render/` и `ui/`.
  - Разделение `App` (единый цикл событий ОС и реестр окон) и `Window` (независимый `Canvas`, `UI`-контекст, фокус, анимации и `drawFn` для каждого окна).
  - Слой оверлеев (`OverlayLayer` / Z-order) в ядре `UI`: отложенная отрисовка поверх основного интерфейса и блокировка кликов по виджетам под активной плавающей панелью или меню.
  - Потокобезопасный `app.Dispatch(fn)` для обновления состояния UI из фоновых горутин с автоматическим пробуждением окна.
  - Навигация фокуса с клавиатуры (`Tab` / `Shift+Tab`, `Enter`, `Escape`) и регистрация горячих клавиш (`Shortcut`).
  - Чёткое разделение кода по модулям без раздувания файлов.
- **Система тем и опций стилизации:**
  - Предустановленные темы: `DeepNavyTheme()`, `DarkTheme()`, `LightTheme()`.
  - Переопределение цветов, радиусов, размеров шрифта, отступов, иконок и состояния `Disabled` на уровне каждого виджета через функциональные опции (`anyui.Bg(...)`, `anyui.Radius(...)`, `anyui.Width(...)`, `anyui.FontSize(...)`, `anyui.Icon(...)`).
- **Движок плавных анимаций (`Animator`):**
  - Интерполяция `float32` значений по ID виджета (hover, нажатие, переключение `Toggle`, появление фокуса, плавный скролл).
  - Умный цикл кадров: таймер (~60 FPS) активен только пока есть незавершённые анимации; после окончания процесс снова спит в `GetMessageW` (0% CPU в простое).
- **Документация:** создание `docs/README.md` (архитектура, быстрый старт) и `docs/theming.md` (темы и опции).

### Фаза 2. SVG-иконки, графика, эффекты и изображения
- **Визуальные эффекты в `render/`:**
  - Градиенты (`LinearGradient`, `RadialGradient`) для фонов, кнопок, карточек и прогресс-баров.
  - Мягкие тени (`BoxShadow`) через SDF для глубины карточек, модалок и выпадающих панелей.
  - `BackdropBlur` (Glassmorphism) — быстрый многопроходный blur под полупрозрачными панелями.
  - Разные радиусы по углам (`CornerRadii{TL, TR, BR, BL}`) для вкладок и сгруппированных контролов.
  - Векторные примитивы (`DrawLine`, `DrawPolyline`, `DrawArc`) для графиков, спарклайнов и кастомного рисования.
- **SVG-движок (`render/svg.go`):**
  - Парсинг и растеризация SVG на чистом Go с кешированием альфа-масок по `(svgHash, sizePx)`.
  - Покраска иконки в произвольный цвет (`tint`) в момент отрисовки (одна иконка для обычного состояния, hover, disabled, светлой и тёмной тем).
- **Вывод изображений и видеокадров (`Image` / `CanvasView`):**
  - Отрисовка внешнего `[]byte` (BGRA/RGBA) или `image.Image` с режимами масштабирования (Fit / Fill / 1:1) и клиппингом.
- **Шрифты:**
  - Регистрация нескольких начертаний (Regular, Bold, Monospace) и fallback-цепочка для символов, отсутствующих в основном шрифте.
- **Документация:** `docs/graphics.md` (градиенты, тени, blur, SVG-иконки, вывод изображений и графиков).

### Фаза 3. Системная интеграция (`platform/`)
- **Системный трей (`SystemTray`) — обязательно:**
  - Иконка в области уведомлений (`Shell_NotifyIconW` на Windows), динамическая смена иконки и текста подсказки (`Tooltip`).
  - События левого/правого/двойного клика.
  - Сворачивание в трей вместо закрытия окна (настраиваемое поведение при `Close`).
  - Нативное контекстное меню трея (`CreatePopupMenu` / `TrackPopupMenu`) с поддержкой обычных пунктов, чекбоксов, disabled-пунктов и разделителей.
- **Системные диалоги:**
  - `OpenFileDialog`, `SaveFileDialog`, `SelectFolderDialog`, `MessageBox`.
- **Управление окном, кастомная шапка и Drag & Drop:**
  - `Minimize`, `Maximize`, `Restore`, `Fullscreen`, чтение/установка позиции и размера окна.
  - `Frameless` / `CustomTitleBar`: окно без системной рамки с поддержкой перетаскивания и Aero Snap (`WM_NCHITTEST`), чтобы размещать `TabBar` и кнопки прямо в заголовке.
  - Drag & Drop файлов из проводника ОС в окно (`WM_DROPFILES`).
- **Многооконность:**
  - `app.OpenWindow(cfg, drawFn)` — открытие и управление дополнительными независимыми окнами из одного `App` (настройки, логи, параллельные окна просмотра).
  - Поддержка дочерних окон (`Parent`) и настраиваемое закрытие (закрытие дочернего окна не завершает `App`; закрытие главного может сворачивать его в трей).
- **Документация:** `docs/system.md` (трей, диалоги, буфер обмена, многооконность, нюансы сборки под старые ОС).

### Фаза 4. Основные контролы (`ui/`)
- **Кнопки и переключатели:**
  - `Button`: текст, только иконка (`IconButton`), иконка + текст, варианты стилей (`Primary`, `Secondary`, `Danger`, `Ghost`), состояние `Disabled`.
  - `Checkbox` (с плавной галочкой и состоянием `Indeterminate` / `Disabled`).
  - `RadioButton` / `RadioGroup`.
  - `Toggle` (с плавной анимацией ползунка).
- **Полноценный ввод текста:**
  - `TextInput`: установка курсора кликом мыши в точную позицию, выделение текста мышью и `Shift + Стрелки`, `Ctrl+A / C / V / X`, режим пароля (`Password()`), иконка слева/справа, кнопка очистки, валидация/фильтр ввода, `ReadOnly` / `Disabled`.
  - `TextArea`: многострочный ввод с переносами и вертикальным скроллом.
- **Списки, комбобоксы и навигация:**
  - `Select` / `ComboBox`: выпадающий список с оверлеем поверх интерфейса, поддержкой скролла и опциональным поиском/фильтром элементов.
  - `ListView`: прокручиваемый список элементов с выделением (одиночным/множественным) и виртуализацией для больших списков.
  - `Tabs`: статические горизонтальные вкладки и вертикальное боковое меню (для настроек и форм).
  - `TabBar`: динамические закрываемые вкладки (как в браузере/IDE) с кнопками `×` и `+`, иконкой/`StatusDot`, обрезкой текста и горизонтальным скроллом при переполнении.
- **Контейнеры и оверлеи:**
  - `ScrollView`: прокрутка колесом мыши и перетаскиванием скроллбара (вертикальная и горизонтальная).
  - `Modal` / `Dialog`: модальное окно с затемнением фона и блокировкой кликов под ним.
  - `Popover`: выпадающая панель с произвольными виджетами внутри (кнопки, тогглы, слайдеры), привязанная к кнопке-якорю.
  - `FloatingPanel`: плавающая панель внутри окна поверх контента (с поддержкой перетаскивания мышью и сворачивания).
  - `Drawer` / `SlidePanel`: выезжающая/автоскрываемая панель от края окна (например, тулбар инструментов или боковая панель).
  - `ContextMenu`: кастомное всплывающее меню по правому клику (подменю, хоткеи, иконки, разделители).
  - `Tooltip`: всплывающая подсказка при наведении.
  - `Separator`, `Badge`, `StatusDot`, `ProgressBar`.
- **Документация:** `docs/widgets.md` (справочник основных контролов с примерами).

### Фаза 5. Дополнительные контролы (`ui/`)
- **Сложные данные и структура:**
  - `Table` / `DataGrid`: таблица с заголовками колонок, ресайзом ширины колонок, сортировкой, выделением строк и виртуализацией.
  - `TreeView`: древовидный список с раскрытием узлов (для каталогов, настроек, иерархий).
  - `SplitPane`: разделение области на 2 панели с перетаскиваемым разделителем (вертикальным/горизонтальным).
  - `Accordion` / `Collapsible`: сворачиваемые секции.
  - Расширение `TabBar`: перетаскивание вкладок (drag-reorder) и открепление вкладки в отдельное окно через `app.OpenWindow`.
- **Расширенный ввод и выбор:**
  - `NumberInput` / `Stepper` (ввод чисел с кнопками +/- и шагом).
  - `Slider` (одиночный ползунок и диапазон `RangeSlider`).
  - `ColorPicker` (выбор цвета + HEX-поле).
  - `DatePicker` (календарь для выбора даты).
- **Уведомления и обратная связь:**
  - `Toast` / `Notification`: всплывающие уведомления (Info, Success, Warning, Error) с автоскрытием.
  - `Spinner` / `Loader`: анимированный индикатор загрузки.
- **Документация:** дополнение `docs/widgets.md` примерами дополнительных контролов.

### Фаза 6. Кроссплатформенность (Linux / macOS)
- Реализация бэкенда `platform_linux.go` (X11 / Wayland) за общим интерфейсом `platform.Window` и `Tray`.
- Адаптация системных диалогов и буфера обмена под Linux, чтобы пользовательский код работал без изменений.

### Фаза 7. Примеры и витрина (`examples/`)
- `examples/hello` — минимальное приложение за 15 строк.
- `examples/tray_app` — приложение с треем, сворачиванием и уведомлениями.
- `examples/settings_form` — форма настроек с табами, инпутами, комбобоксами и тогглами.
- `examples/gallery` — интерактивная витрина всей палитры контролов со сменой тем на лету.

## Стандарты документации (`docs/`)
Документация пишется параллельно с кодом, чтобы любой разработчик мог подключить `anyui` за 1 минуту:
- **`docs/README.md`** — установка, быстрый старт, жизненный цикл `App`/`Window`, многопоточность (`Dispatch`).
- **`docs/theming.md`** — готовые темы, создание своей палитры, таблица всех опций стилизации (`Option`: размеры, отступы, цвета, радиусы, шрифты, disabled).
- **`docs/widgets.md`** — справочник по каждому контролу: назначение, сигнатура, список всех доступных свойств/опций и готовый копируемый пример кода.
- **`docs/graphics.md`** — работа с SVG-иконками, градиентами, тенями, blur и выводом `Image`/`CanvasView`.
- **`docs/system.md`** — трей, контекстное меню трея, диалоги файлов, буфер обмена, Drag & Drop, многооконность и сборка под старые Windows.
