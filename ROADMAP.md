# План развития фреймворка AnyUI (`anyui`)

## Концепция и цель
`anyui` — лёгкий, встраиваемый кроссплатформенный UI-фреймворк на Go без WebView2 и без зависимости от OpenGL/GPU.
Ключевые принципы:
- Любое Go-приложение подключает один пакет `anyui` и сразу строит интерфейс без привязки к конкретной предметной области.
- Минимальный размер бинарника, быстрый старт, ~0% нагрузки на CPU в простое.
- Работа на любых машинах, включая серверные ОС, RDP и среды без аппаратного ускорения.
- Полная кастомизация тем, цветов, радиусов, шрифтов и стилей каждого контрола.
- Документация и рабочие примеры в `docs/` и `examples/` создаются параллельно с каждой фазой.

---

## Целевой API для разработчика

```go
package main

import "anyui"

func main() {
	app := anyui.NewApp(anyui.Config{
		Title:  "My App",
		Width:  1000,
		Height: 650,
		Theme:  anyui.DeepNavyTheme(),
		Tray: &anyui.TrayConfig{
			Tooltip: "My App",
			Menu: []anyui.MenuItem{
				{Label: "Показать", OnClick: func(a *anyui.App) { a.Show() }},
				{Separator: true},
				{Label: "Выход", OnClick: func(a *anyui.App) { a.Quit() }},
			},
		},
	})

	app.Run(func(ui *anyui.UI) {
		ui.Button("btn_save", "Сохранить", anyui.Icon(saveSVG), anyui.Primary())
	})
}
```

## Фазы реализации

### Фаза 1. Архитектура, фасадный пакет и движок анимаций — [x] Готово
- [x] **Единый корневой пакет `anyui/` и задел под многооконность:**
  - [x] Публичный фасад (`App`, `Window`, `UI`, `Config`, `Theme`, `Option`), скрывающий внутренние детали `platform/`, `render/` и `ui/`.
  - [x] Разделение `App` (единый цикл событий ОС и реестр окон) и `Window` (независимый `Canvas`, `UI`-контекст, фокус, анимации и `drawFn` для каждого окна).
  - [x] Слой оверлеев (`OverlayLayer` / Z-order) в ядре `UI`: отложенная отрисовка поверх основного интерфейса и блокировка кликов по виджетам под активной плавающей панелью или меню.
  - [x] Потокобезопасный `app.Dispatch(fn)` для обновления состояния UI из фоновых горутин с автоматическим пробуждением окна.
  - [x] Навигация фокуса с клавиатуры (`Tab` / `Shift+Tab`, `Enter`, `Escape`) и регистрация горячих клавиш (`Shortcut`).
  - [x] Чёткое разделение кода по модулям без раздувания файлов.
- [x] **Система тем и опций стилизации:**
  - [x] Предустановленные темы: `DeepNavyTheme()`, `DarkTheme()`, `LightTheme()`.
  - [x] Переопределение цветов, радиусов, размеров шрифта, отступов, иконок и состояния `Disabled` на уровне каждого виджета через функциональные опции (`anyui.Bg(...)`, `anyui.Radius(...)`, `anyui.Width(...)`, `anyui.FontSize(...)`, `anyui.Icon(...)`).
- [x] **Движок плавных анимаций (`Animator`):**
  - [x] Интерполяция `float32` значений по ID виджета (hover, нажатие, переключение `Toggle`, появление фокуса, плавный скролл).
  - [x] Умный цикл кадров: таймер (~60 FPS) активен только пока есть незавершённые анимации; после окончания процесс снова спит в `GetMessageW` (0% CPU в простое).
- [x] **Документация:** создание `docs/README.md` (архитектура, быстрый старт) и `docs/theming.md` (темы и опции).

## Стандарты документации (`docs/`)
Документация пишется параллельно с кодом, чтобы любой разработчик мог подключить `anyui` за 1 минуту:
- **`docs/README.md`** — установка, быстрый старт, жизненный цикл `App`/`Window`, многопоточность (`Dispatch`).
- **`docs/theming.md`** — готовые темы, создание своей палитры, таблица всех опций стилизации (`Option`: размеры, отступы, цвета, радиусы, шрифты, disabled).
- **`docs/widgets.md`** — справочник по каждому контролу: назначение, сигнатура, список всех доступных свойств/опций и готовый копируемый пример кода.
- **`docs/graphics.md`** — работа с SVG-иконками, градиентами, тенями, blur и выводом `Image`/`CanvasView`.
- **`docs/system.md`** — трей, контекстное меню трея, диалоги файлов, буфер обмена, Drag & Drop, многооконность и сборка под старые Windows.
